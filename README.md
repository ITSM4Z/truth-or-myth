# Truth or Myth (حقيقة أم خرافة)

An interactive web-based flashcard game built for the Mental Health Forum (*لكل صوت أثر*). Players classify common statements about mental health into **Facts** (حقيقة) or **Myths** (خرافة) using drag-and-drop, followed by a scored results screen with verified medical explanations and sources.

## Features

- **Flashcard Deck**: Cards appear stacked one after another. Dragging the top card reveals the next one queued behind it.
- **Flexible Drag & Drop**: Powered by `@dnd-kit`. Supports dragging from deck to piles, moving cards between Fact and Myth piles, or returning a card back to the deck for reclassification.
- **Randomized Questions**: Statements are shuffled on every game start so each playthrough has a fresh order.
- **Medical Sources & Explanations**: 15 authentic statements backed by citations from the WHO, APA, NIMH, Mayo Clinic, Harvard Medical School, and Yale University.
- **Live Timer & Submission Guard**: Tracks completion time and prevents submitting before categorizing all cards.
- **Live Leaderboard & Supabase**: Real-time ranking with top medals, anti-duplication logic (tracks personal bests), and kiosk viewing from both the main menu and postgame screens.

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ITSM4Z/Truth-Or-Myth.git
   cd truth-or-myth
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser.

## Database & Leaderboard Setup (Supabase)

The game uses Supabase to record student scores, track completion times, and power the live booth leaderboard.

### 1. Database Table & Policies

Run the following script in the Supabase **SQL Editor** to set up the `leaderboard` table and permissions:

```sql
create table public.leaderboard (
    id bigint generated by default as identity primary key,
    player_name text not null,
    score int not null,
    time_seconds int not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable Row Level Security
alter table public.leaderboard enable row level security;

-- Allow public inserts and reads for booth kiosk
create policy "Allow public insert" on public.leaderboard for insert to anon with check (true);
create policy "Allow public read" on public.leaderboard for select to anon using (true);
create policy "Allow public update" on public.leaderboard for update to anon using (true);
```

### 2. Environment Variables

Create a `.env` file in the root directory (or add these under **Environment Variables** in your hosting dashboard, e.g., Vercel / Netlify):

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

The game includes built-in duplicate prevention: if a student plays more than once, it updates their entry only if they achieve a better score or a faster time. If credentials are not configured, the app runs completely fine client-side without crashing.

### 3. Resetting the Leaderboard

To wipe test scores and reset the leaderboard counter before an event starts, run this in Supabase SQL Editor:

```sql
truncate table public.leaderboard restart identity;
```
